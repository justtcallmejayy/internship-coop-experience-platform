# Branch structure

A concise overview of repository branches and their purpose.

- main: stable working code.
- dev: ongoing development branch
- feature/auth: Phase 3 - authentication work
- feature/profile: Phase 4 - profile work
- feature/experience-entries: Phase 5 - entries CRUD work
- feature/moderation: Phase 5 - admin moderation work
- feature/browse-search: Phase 6 - browse/search/filter/sort work
